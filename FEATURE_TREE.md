# Oasis feature tree

## Coverage and evidence

The whole-project index below covers every registered tRPC domain plus shared infrastructure. Domain subfeatures are indexed in [API inventory](docs/feature-tree/api-domains.md). The [existing architecture map](docs/architecture/component-relationships.md) supplies broader UI navigation; it is older and must be verified against source. [Library](docs/feature-tree/library.md) is source-reviewed in detail for this task. Other domains are `partial`: router entry points and procedure names are verified, but exhaustive UI, service, event and permission relationships remain to be audited. No claim of exhaustive behavioral verification is made.

Graph: [persistent JSON](graphify-out/graph.json), [coverage report](graphify-out/GRAPH_REPORT.md). Graph node IDs can be found by `source_file` and `label`; code and tests remain authoritative. Reuse the existing router and domain helpers; never create parallel domain owners merely because the graph lacks detail.
