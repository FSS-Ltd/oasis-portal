# Claude Code — Project Rules

## Branch naming

Always use the project's standard branch prefixes. Never prefix branches with `claude/` or any other agent identifier.

Standard prefixes:
- `feat/` — new features
- `fix/` — bug fixes
- `chore/` — maintenance, dependency updates, tech debt
- `refactor/` — code restructuring without behaviour change

Examples: `fix/listusers-student-email`, `feat/mobile-pace-validation`
